# Vector rear speaker cover (3D print)

Replacement for the lost **black head-back speaker grille** (the part with 2×5 horizontal slots).

## Files

| File | Use |
|------|-----|
| `vector_speaker_cover.stl` | Slice & print |
| `vector_speaker_cover.scad` | Tweak sizes in [OpenSCAD](https://openscad.org/) |
| `gen_stl.py` | Regenerate STL without OpenSCAD |

## Print

- **Size (approx):** 34 × 36 × ~3.4 mm (estimated from photos — not OEM CAD)
- **Material:** PETG/ABS preferred; PLA OK for a fit check
- **Layer:** 0.12–0.16 mm, 100% infill
- **Fit:** if too tight/loose, scale XY ±2–5% in the slicer, or edit `width_mm` / `height_mm` in the `.scad`

## Notes

- Side clip is approximate; you may need to sand or glue if the OEM snap doesn’t catch.
- This is the **cover only** — not the speaker driver or blue lead.
