Extract the **whole** zip → run **`START-HERE.bat`**

## Controls

| Key | Action |
|-----|--------|
| **1 / 2 / 3** | Select Rock / Grass / Oak Planks (hotbar) |
| **F** | Toggle fly mode |
| **Space** | Jump, or fly up |
| **Shift** | Fly down |
| **WASD** | Move |
| **LMB / RMB** | Place / break |
| **Enter** | Save |
| **Esc** | Quit |

Hotbar is at the bottom; yellow **F** badge appears when flying.
