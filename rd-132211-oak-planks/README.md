1. Delete any old extracted folder
2. Extract this zip
3. Run **`START-HERE.bat`**
4. Watch the **console window** — it prints `Selected [2] Grass` / `FLY ON` when keys work

## Controls

- **1 / 2 / 3** — Rock / Grass / Oak Planks
- **Mouse wheel** — cycle blocks
- **F or G** — fly on/off (yellow badge top-left)
- **Space / Shift** — fly up / down
- Hotbar = 3 colored squares at the bottom (gray / green / brown)
